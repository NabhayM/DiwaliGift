Project Type: Interactive festival celebration website, password-protected, for a long-distance couple.

Landing / Cover Page:
	•	Display 4 decorative gates representing festivals: Dhanteras, Choti Diwali, Diwali, Govardhan Pooja.
	•	Background: rich golden and warm tones with subtle sparkles or light particles.
	•	Password protection: each gate is locked until the password is provided by me.
	•	Gate interaction: when clicked (with correct password), the user can enter the festival page.
	•	Font style: elegant, festive, readable.
	•	Optional line: “Step through the gates to celebrate the festivals together.”

Dhanteras Page:
	•	Background: initially dark to symbolize night / mystery.
	•	Centerpiece: a diya (lamp) with simple animated flame.
	•	Button labeled “Light Diya”.
	•	When clicked:
	•	The diya flame lights up.
	•	Darkness fades away, revealing a warm golden background.
	•	Message appears with sparkling/festive effect: “Maa Lakshmi humare pyaar par ashirvaad banaye rakhe aur sukh, shanti aur dhan se bhara jeevan de.”
	•	Decorative animations appear: falling gold/silver coins, subtle sparkles, or festive confetti.
	•	Theme: gold, prosperity, blessings of Maa Lakshmi.

Other Festival Pages (Choti Diwali, Diwali, Govardhan Pooja):
	•	Each with an initially dark background.
	•	Centerpiece: a diya, lamp, or festival-specific symbol.
	•	Interactive button to “light up” the main element.
	•	Upon activation: darkness fades, revealing the festive scene with thematic decorations, animations, and a personalized blessing message.
	•	Decor examples: lamps, fireworks, flowers, Govardhan hill or cow elements for Govardhan Pooja.

Animations & Interactivity:
	•	Smooth, elegant animations for diya flames, sparkles, coins, confetti, or fireworks.
	•	Messages appear gradually with glow/sparkle effects.
	•	Background transitions from dark to festive color upon user interaction.
	•	All animations are subtle and elegant, maintaining a warm, magical feel.

General Design Guidelines:
	•	Elegant, festive fonts and typography.
	•	Mobile-friendly layout.
	•	Consistent gold, warm, and celebratory color palette across all pages.
	•	Minimal distractions, focus on interactivity and magical reveal of blessings.
	•	Only accessible via password, giving a surprise / controlled reveal to the user.
